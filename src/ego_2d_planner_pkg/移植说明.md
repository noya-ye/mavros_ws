# Diff-Planner 2D / ROS 2 Humble 源码功能包

解压得到 `ego_2d_planner_pkg`，整体放入你现有工作空间的 `src/`。若已有同名旧 EGO 包，先移出 `src/` 备份，再放入本包，避免重名。依赖使用你已有的 ROS 2 Humble、Eigen3、quadrotor_msgs 环境，本包没有附带或替换这些依赖。

在已经 source 原 ROS 和依赖环境的工作空间根目录执行：

```bash
colcon build --packages-select ego_2d_planner_pkg --cmake-args -DCMAKE_BUILD_TYPE=Release
source install/setup.bash
ros2 launch ego_2d_planner_pkg ego_2d_planner.launch.xml
```

主参数文件是 `config/ego_2d_planner.yaml`。默认输入 `/cloud_registered_filtered`、`/fastlio2/lio_odom`，坐标系 `lidar`，正常高度 1.0 m。移植前确认话题、点云/里程计的统一物理坐标和高度；本程序不进行 TF 坐标转换。修改源码目录里的 YAML 后，需要重新构建更新安装副本；也可以直接加载所编辑文件：

```bash
ros2 launch ego_2d_planner_pkg ego_2d_planner.launch.xml \
  config:="$(pwd)/src/ego_2d_planner_pkg/config/ego_2d_planner.yaml" use_sim_time:=false
```

- 默认膨胀半径 `grid_map/inflate_radius: 0.45` m；你的机体半径为 0.25 m，额外余量仍需结合实际误差确认。该半径按 0.05 m 离散格点计算。
- 正常速度 0.35 m/s、加速度 0.8 m/s²；调整时规划器和服务器限值一起修改。
- yaw 锁定启动后第一帧有效里程计航向，yaw_dot=0。正常 z 固定，急停保持实际里程计 XYZ。
- 内部轨迹为 `/ego_2d_planner/polynomial_2d`、`Polynomial2D`；规划器和轨迹服务器一起更新。对飞控的 `/position_cmd` 类型和字段沿用原 `quadrotor_msgs/PositionCommand`。
- 启动前停止旧规划器及旧服务器，保证 `/position_cmd` 只有一个控制发布源。launch 不负责解锁、起飞或切换 Offboard。

可选贴边参数文件 `config/ego_2d_close_obstacles.yaml` 仅改变 dist0=0.05、lambda_fitness=3.0、lambda_smooth=0.3，膨胀保持 0.45 m。它是完整 YAML，话题和高度等也需改成真机值。使用方式：

```bash
ros2 launch ego_2d_planner_pkg ego_2d_planner.launch.xml \
  config:="$(pwd)/src/ego_2d_planner_pkg/config/ego_2d_close_obstacles.yaml"
```

核心源码与当前项目一致，旧 B 样条参考文件未参与编译或运行；完整算法和接口见 `DIFF_PLANNER_2D.md`。此包经过 x86_64 WSL Ubuntu 22.04 / Humble 验证，真机闭环飞行尚未验证。
